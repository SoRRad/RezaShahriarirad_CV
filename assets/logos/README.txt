Place logo image files here. The filename must match the logo_file value used in experience.csv, education.csv, or affiliations.csv exactly (e.g. mayo-clinic.png, sums.png, tavs.png). Supported formats: PNG, SVG, JPG. Recommended size: 80x80px minimum, square or near-square. If no logo file exists for an org, the page displays coloured initials from logo_initials instead.
